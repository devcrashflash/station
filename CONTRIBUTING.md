# Contributing to Station

Bug reports and suggestions are welcome. Code contributions require acceptance
of the [Station Contributor License Agreement](CONTRIBUTOR_LICENSE_AGREEMENT.md).

When opening a pull request:

1. Read the Contributor License Agreement.
2. Keep the CLA acceptance checkbox in the pull request template checked.
3. If contributing for a company or another legal entity, name that entity in
   the pull request and confirm that you are authorized to contribute its code.
4. Identify third-party code, assets, or generated material and their licenses.

Pull requests cannot be merged until the CLA check passes. Accepting the CLA
does not guarantee that a contribution will be accepted.
